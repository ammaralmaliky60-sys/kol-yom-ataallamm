# كل يوم أتعلم

تطبيق تعليمي عربي يعمل في المتصفح، ويدعم الإضافة إلى الشاشة الرئيسية كتطبيق PWA. يحتوي على مسارات للإنجليزية والكمبيوتر والثقافة العامة، واختبارات بنتائج فورية وحفظ للتقدم وتدريب صوتي وفق إمكانات المتصفح، بواجهة زجاجية وألوان زاهية.

## التشغيل

يتطلب Node.js حديثاً (الإصدار 20 أو أحدث). لا توجد حزم تشغيل خارجية ولا يلزم تثبيت npm.

```bash
git clone https://github.com/ammaralmaliky60-sys/kol-yom-ataallamm.git
cd kol-yom-ataallamm
node server.mjs
```

افتح `http://localhost:3000` على الجهاز الذي يشغل الخادم. لتغيير المنفذ:

```bash
PORT=8080 node server.mjs
```

للفحص:

```bash
npm run build
npm test
```

الخادم المحلي مخصص للتطوير. للنشر، ارفع محتويات `dist` إلى استضافة ملفات ثابتة تدعم HTTPS وتقدم ملفات JavaScript وmanifest وservice worker بأنواع MIME الصحيحة. يجب أن تعيد طلبات الملفات المفقودة خطأ 404، وأن تسمح بتحديث ملف service worker دون تخزين طويل.

## التشغيل على iPhone

1. افتح رابط النسخة المنشورة عبر **HTTPS** في Safari، وانتظر اكتمال فتحها وتنزيل الملفات للاستخدام دون اتصال.
2. اضغط زر **المشاركة** في Safari.
3. اختر **إضافة إلى الشاشة الرئيسية** ثم **إضافة**. إذا لم يظهر الخيار، مرّر قائمة إجراءات المشاركة.
4. افتح التطبيق من الأيقونة. اسمح بالميكروفون عند بدء التدريب الصوتي.

عنوان `localhost` على iPhone يشير إلى الهاتف نفسه؛ لا يشير إلى حاسوبك. يمكن معاينة الواجهة عبر عنوان IP للحاسوب على الشبكة نفسها، لكن اتصال HTTP العادي لا يكفي لتفعيل الميكروفون وPWA. استخدم استضافة HTTPS لتجربة هذه الوظائف على الهاتف. تختلف بعض أسماء قوائم Safari حسب إصدار iOS.

## التقدم والخصوصية والنسخ الاحتياطي

يحفظ التطبيق التقدم والنتائج والكلمات المفضلة محلياً في المتصفح. إعادة تحميل الصفحة لا تمسحها. حذف بيانات الموقع أو تغيير المتصفح أو الجهاز قد يفقدها؛ لا توجد مزامنة حسابات أو قاعدة بيانات سحابية في هذه النسخة. استخدم أدوات تصدير واستيراد التقدم في الملف الشخصي لإنشاء نسخة احتياطية، واحتفظ بالملف في مكان خاص.

لا يرفع التطبيق تسجيلك إلى خادم خاص به. التعرف على الكلام وظيفة يقدمها المتصفح، وقد يستخدم خدمة خارجية تابعة لمزود المتصفح ويتطلب اتصالاً بالإنترنت. راجع سياسة المتصفح قبل استخدامه للمعلومات الحساسة.

## الصوت والعمل دون اتصال

- نطق الكلمات والجمل يستخدم `speechSynthesis`، وتعتمد جودة الصوت وتوفره دون اتصال على الأصوات المثبتة في الجهاز.
- التعرف على الكلام يستخدم `SpeechRecognition` أو `webkitSpeechRecognition` عند توفرهما. قد لا يتوفر في بعض المتصفحات أو إصدارات iOS، وقد يحتاج إلى اتصال بالإنترنت وإذن الميكروفون.
- مقارنة الكلام تعتمد على **الكلمات التي تعرّف إليها المتصفح**؛ ليست قياساً صوتياً دقيقاً لمخارج الحروف ولا تشخيصاً للنطق.
- التسجيل يستخدم `getUserMedia` و`MediaRecorder` عند دعمهما، ويمكن الاستماع إلى التسجيل للتقييم الذاتي. يتطلب الميكروفون سياقاً آمناً HTTPS أو localhost وإذن المستخدم.
- يخزن service worker ملفات التطبيق محلياً بعد الزيارة الأولى الناجحة. يجب تنزيل التطبيق أولاً وأنت متصل. قد يزيل iOS البيانات المخزنة عند نقص المساحة أو بعد فترة من عدم الاستخدام.

## بنية المشروع وتوسيع المنهج

```text
dist/
  index.html                 صفحة التطبيق العربية
  assets/                    الرسوم والأيقونات المحلية
  data/english.js            دروس الإنجليزية ودليل النطق
  data/computer.js           دروس الكمبيوتر
  data/culture.js            دروس الثقافة العامة
  modules/audio.js           النطق والتعرف والتسجيل
  manifest.webmanifest       إعدادات تثبيت PWA
  sw.js                      التخزين للاستخدام دون اتصال
server.mjs                   خادم محلي بسيط
scripts/check.mjs            فحص البنية والمحتوى
```

المحتوى منفصل عن الواجهة. يمكن إضافة درس إلى مصفوفة المسار المناسب، مع معرف فريد، وفق هذا الشكل:

```js
{
  id: 'en-unique-id',
  track: 'english',
  level: 'A1',
  unit: 'الأساسيات',
  title: 'عنوان الدرس',
  description: 'وصف واضح لمهارة الدرس',
  minutes: 8,
  sections: [{ title: 'الفكرة', body: 'شرح عربي واضح', example: 'Hello.', translation: 'مرحباً.' }],
  vocabulary: [{ word: 'Hello', meaning: 'مرحباً', pronunciation: 'هَلو', example: 'Hello, Sara.', translation: 'مرحباً يا سارة.' }],
  practice: 'تطبيق عملي محدد',
  questions: [{
    type: 'choice',
    prompt: 'ما معنى Hello؟',
    options: ['مرحباً', 'شكراً', 'وداعاً'],
    answer: 'مرحباً',
    explanation: 'تستخدم Hello للتحية.'
  }]
}
```

الأنواع المتاحة للأسئلة: `choice` و`input` و`order` و`boolean` و`listening`. اكتب الإجابة كنص، مع تفسير مفيد لكل سؤال. في الاختيار يجب أن تكون الإجابة ضمن الخيارات. في سؤال الترتيب تكون الخيارات كلمات الجملة وتكون الإجابة الجملة المرتبة. لتدريب الاستماع أضف `audio` بالنص الإنجليزي المطلوب نطقه. استخدم النصوص العادية في المحتوى، ومعرّفات ثابتة حتى يظل تقدم المستخدم مرتبطاً بالدروس الصحيحة بعد التحديث.

حافظ على التدرج من الأساسيات إلى المتقدم عند إضافة المحتوى، وارفع إصدار مخبأ service worker عند تغيير ملفات التطبيق. يمكن لاحقاً استبدال مصدر البيانات بواجهة API وإضافة حسابات وقاعدة بيانات ومزامنة، مع الإبقاء على معرفات الدروس. النشر الحالي ثابت ولا يتضمن محرراً سحابياً للمحتوى.

## حدود تعليمية واضحة

تنظيم الإنجليزية بمستويات CEFR وسيلة لترتيب المحتوى. إنه ليس اعتماداً من جهة امتحانات، ونتائج الاختبارات المحلية لا تمنح شهادة مستوى معتمدة. المنهج الحالي مكتبة تأسيسية قابلة للتوسع؛ الوصول إلى إتقان شامل يحتاج محتوى إضافياً وممارسة مطولة وتقييماً بشرياً للتحدث والكتابة. مصادر دروس الثقافة مدرجة كقراءات مرجعية، وتحتاج المراجعة التحريرية دورياً، خصوصاً الموضوعات العلمية والتقنية المتغيرة.

## نسخة GitHub

هذا المستودع يحتوي الشفرة والدليل التعليمي والتطويري ونسخة PDF. مجلد dist جاهز للاستضافة. يتم تشغيل نشر GitHub Pages من Actions عبر Deploy educational PWA to GitHub Pages بعد تفعيل Pages.


## تفعيل رابط الموقع بخطوة إعداد واحدة

فرع `gh-pages` جاهز ويحتوي التطبيق الثابت والدليل وملفات PWA. لتفعيله من GitHub:

1. افتح **Settings → Pages** في هذا المستودع.
2. اختر **Deploy from a branch** ضمن **Source**.
3. اختر الفرع **gh-pages** والمجلد **/ (root)** ثم اضغط **Save**.

الرابط المتوقع بعد اكتمال بناء Pages:
https://ammaralmaliky60-sys.github.io/kol-yom-ataallamm/

رفع الشفرة لا يفعّل Pages وحده. رفض اتصال GitHub الحالي إنشاء موقع Pages تلقائياً بخطأ صلاحيات 403؛ إعداد Pages أعلاه يتم من حساب مالك المستودع. بعد الحفظ قد يستغرق البناء دقيقة أو دقيقتين.

للتحديث لاحقاً: يمكن نشر محتويات `dist` إلى فرع `gh-pages` مع إبقاء `.nojekyll`، أو اختيار GitHub Actions وتشغيل سير النشر المرفق. ارفع إصدار CACHE في sw.js عند تحديث ملفات التطبيق.
