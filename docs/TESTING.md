# التحقق وحدوده

- فحص بنية 146 درساً و584 سؤالاً، وJavaScript وملفات PWA والأيقونات.
- 23 اختباراً آلياً للمحرك والحفظ والتصحيح والنطق النصي: اجتازت.
- اجتازت 17 مجموعة فحص لواجهة Chromium دون أخطاء JavaScript، وتشمل: التنقل، البحث، المفضلة، قفل الدروس، فشل/نجاح الاختبارات، ثمانية دروس متتابعة، ترتيب الكلمات، حفظ النتائج بعد التحديث، عدم مضاعفة النقاط، الاسم والهدف، التصدير والاستيراد، سجل الإجابات، تحديد المستوى، النطق، والتخزين دون اتصال.
- النتائج الفورية: لا يوجد زر تحقق إضافي؛ تصحيح الاختيارات فور التحديد، والكتابة عند الانتهاء، والترتيب عند اختيار آخر كلمة، مع منع احتساب الإجابة مرتين.
- تعديل بدء الاختبار: اختبارا الحاسوب والثقافة يفتحان مباشرة، دون اشتراط مربع التمرين العملي. فتح الدرس التالي يبقى مشروطاً بالاجتياز.
- التسجيل اختُبر عبر getUserMedia وMediaRecorder في Chromium بميكروفون اصطناعي، مع إنشاء ملف صوت وإيقاف مسارات الميكروفون.
- التعرف على الكلام اختُبر بمحاكاة خدمة المتصفح؛ لم يجر اختبار خدمة التعرف عن بعد أو جودة الميكروفون الحقيقي.
- المحاكاة الهاتفية ليست اختبار Safari فعلياً. لم يتوفر iPhone أو WebKit قابل للتشغيل في بيئة الفحص.
- المصادر التعليمية في دروس الثقافة مراجع للقراءة وليست توثيقاً لمراجعة علمية مستقلة لكل سطر. تنظيم CEFR ليس اعتماداً أو شهادة.

لتكرار فحوص البيانات والمحرك: npm run build ثم npm test. للاختبار التفاعلي راجع DEVELOPMENT_GUIDE.md.
