# التحقق وحدوده

## التحديث الحالي - 7 نوفمبر 2026

- اجتازت الاختبارات الآلية الـ47 وفحص البناء: 146 درسًا و589 سؤالًا مؤلفًا، و735 سؤالًا مع التحديات المركبة، وجميع ملفات التخزين المسبق موجودة.
- اختُبر الانتقال التلقائي في اختبار حاسوب كامل، مع عرض 100% وتصحيح الإجابات الخمس في النهاية فقط. اختيار الإجابة ينتقل مباشرة، والكتابة تتطلب زر المتابعة أو Enter؛ الخروج من حقل الكتابة لا يؤكد الإجابة.
- ظهرت قياسات حالة سارة 14 و9 سم وبقية المعطيات في السؤال المركّب ضمن المراجعة الشاملة.
- تحققت الاختبارات الآلية من إزالة الخطأ بعد إجابة أحدث صحيحة، وربط أخطاء الوحدات وتحديد المستوى والمراجعة والاستماع بالدروس، والتوافق مع السجلات القديمة غير الملتبسة.
- فُحصت عروض 320 و390 و768 و1024 و1440 بكسل دون تجاوز أفقي. اختُبر إغلاق قائمة الهاتف بـEscape، والتفاف التركيز داخلها، ومنع تركيز عناصرها المغلقة.
- لم تظهر أخطاء أو تحذيرات في سجل المتصفح خلال هذه التجربة. لم يُختبر ميكروفون فعلي أو Safari أو تثبيت PWA في هذا التحديث. سلوك الرجوع إلى التخزين عند انقطاع الشبكة اختُبر آليًا، وليس بانقطاع فعلي على جهاز هاتف.

## سجل التحقق السابق

- فحص بنية 146 درساً و584 سؤالاً، وJavaScript وملفات PWA والأيقونات.
- 23 اختباراً آلياً للمحرك والحفظ والتصحيح والنطق النصي: اجتازت.
- اجتازت 17 مجموعة فحص لواجهة Chromium دون أخطاء JavaScript، وتشمل: التنقل، البحث، المفضلة، قفل الدروس، فشل/نجاح الاختبارات، ثمانية دروس متتابعة، ترتيب الكلمات، حفظ النتائج بعد التحديث، عدم مضاعفة النقاط، الاسم والهدف، التصدير والاستيراد، سجل الإجابات، تحديد المستوى، النطق، والتخزين دون اتصال.
- كان الإصدار السابق يعرض التصحيح بعد كل إجابة؛ استُبدل هذا السلوك في التحديث الحالي بالانتقال التلقائي والتصحيح في النهاية.
- تعديل بدء الاختبار: اختبارا الحاسوب والثقافة يفتحان مباشرة، دون اشتراط مربع التمرين العملي. فتح الدرس التالي يبقى مشروطاً بالاجتياز.
- التسجيل اختُبر عبر getUserMedia وMediaRecorder في Chromium بميكروفون اصطناعي، مع إنشاء ملف صوت وإيقاف مسارات الميكروفون.
- التعرف على الكلام اختُبر بمحاكاة خدمة المتصفح؛ لم يجر اختبار خدمة التعرف عن بعد أو جودة الميكروفون الحقيقي.
- المحاكاة الهاتفية ليست اختبار Safari فعلياً. لم يتوفر iPhone أو WebKit قابل للتشغيل في بيئة الفحص.
- المصادر التعليمية في دروس الثقافة مراجع للقراءة وليست توثيقاً لمراجعة علمية مستقلة لكل سطر. تنظيم CEFR ليس اعتماداً أو شهادة.

لتكرار فحوص البيانات والمحرك: npm run build ثم npm test. للاختبار التفاعلي راجع DEVELOPMENT_GUIDE.md.
